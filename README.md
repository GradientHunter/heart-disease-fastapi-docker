# Heart Disease Prediction API

A simple FastAPI application that serves predictions from a Random Forest classifier trained on the Heart Disease Dataset specified in the assignment. The application is Dockerized and can be deployed to Render.

## Project structure

```text
heart_disease_fastapi_docker/
├── app/
│   ├── __init__.py
│   ├── main.py
│   └── schemas.py
├── model/
│   └── heart_model.joblib   # generated by train_model.py
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
├── train_model.py
├── heart.csv                # downloaded dataset; not committed
└── README.md
```

## 1. Dataset and model training

1. Download the dataset from:
   https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset
2. Extract the CSV file and place it in the project root with the filename `heart.csv`.
3. Install the Python dependencies and train the model:

```bash
python -m venv .venv
```

Activate the environment:

Windows PowerShell:
```powershell
.venv\Scripts\Activate.ps1
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install dependencies and train:
```bash
pip install -r requirements.txt
python train_model.py
```

The training script expects these 13 feature columns:
`age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal`

The target column must be named `target` (0 = absence, 1 = presence). The trained model is saved to `model/heart_model.joblib`.

## 2. Run locally without Docker (optional)

```bash
uvicorn app.main:app --reload
```

Open Swagger UI:
http://localhost:8000/docs

## 3. Docker build and run

Build:
```bash
docker-compose build
```

Run:
```bash
docker-compose up
```

Open Swagger UI:
http://localhost:8000/docs

Stop:
```bash
docker-compose down
```

## 4. API endpoints

### GET `/health`

Example response:
```json
{"status": "healthy"}
```

### GET `/info`

Example response:
```json
{
  "model_type": "RandomForestClassifier",
  "features": [
    "age", "sex", "cp", "trestbps", "chol", "fbs", "restecg",
    "thalach", "exang", "oldpeak", "slope", "ca", "thal"
  ]
}
```

### POST `/predict`

Example request:
```json
{
  "age": 52,
  "sex": 1,
  "cp": 0,
  "trestbps": 125,
  "chol": 212,
  "fbs": 0,
  "restecg": 1,
  "thalach": 168,
  "exang": 0,
  "oldpeak": 1.0,
  "slope": 2,
  "ca": 2,
  "thal": 3
}
```

Example response:
```json
{"heart_disease": true}
```

The example values are for API testing only and are not a medical assessment.

## 5. Deploy to Render

1. Train the model first so `model/heart_model.joblib` exists.
2. Commit the project files, including `model/heart_model.joblib`, to a GitHub repository. Do not commit the downloaded `heart.csv` unless your course specifically requires it.
3. Push the repository to GitHub.
4. In Render, create a new **Web Service** and connect the repository.
5. Choose **Docker** as the environment. Keep the Dockerfile at the repository root and use the root as the build context.
6. Deploy. Render will build the Docker image and start the service using the Dockerfile command.
7. Test:
   - `https://YOUR-RENDER-URL/health`
   - `https://YOUR-RENDER-URL/info`
   - `https://YOUR-RENDER-URL/docs`

Use Swagger UI or Postman to send a `POST /predict` request with the JSON example above.

## Notes

- The model is trained locally and packaged into the Docker image.
- The API returns the required boolean field `heart_disease`.
- This educational assignment model is not intended for medical diagnosis or treatment decisions.
